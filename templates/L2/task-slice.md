## 0. 切片规则

| 规则 | 说明 |
|---|---|
| 一个切片 = 一个可验收单元 | 完成时能跑通它列出的 AC，不是"代码写完了" |
| 不跨 D 阻塞 | 切片内出现 ⚠️`D-*` → 拆出阻塞部分，剩余先做 |
| 缺口标注 | 涉及 `G-*` 的切片必须在 PR 里列出 `// GAP: G-xx` |
| 契约先行 | 前后端并行的切片，先冻结 OpenAPI 对应片段 |
| 五态是 DoD | 缺任一态不算完成（总览 §3.1） |
