## 2. 运行检查

```bash
npm run check            # 七类检查，CI 跑的就是这条
npm run generate         # 重新生成 generated/ 与各 .md 的生成区
npm test                 # node --test
```

`npm run check` 红了不要绕过。它检查的七类问题（schema、状态机闭合、ID 引用、生成区一致、禁令覆盖、复制中文标签、覆盖矩阵完整性）每一类都对应一种已经发生过的漂移。

消费仓库各自跑 `verify:contracts`，比对本仓库签入的契约副本与本库 `generated/`。
